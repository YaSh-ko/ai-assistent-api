Delёz API — документация

Что это такое

Delёz — интеллектуальный персональный ассистент для самоанализа и ведения дневника наблюдений. Название и концепция вдохновлены философией ризомы Жиля Делёза: вместо линейного дневника пользователь получает живой граф, где события, эмоции и выводы связаны между собой.

Бэкенд написан на Python (FastAPI) и работает с тремя базами данных:

  • PostgreSQL — основное хранилище пользователей, записей и диалогов.
  • Neo4j — граф ризомы: узлы Entry, Concept, Goal, Experiment, Analysis.
  • ChromaDB — векторные эмбеддинги для RAG-поиска (в разработке).

Production-домен: https://delez.tech

Аутентификация и JWT RS256

После успешного входа сервер выдаёт сессионный токен в виде JWT, подписанного алгоритмом RS256 (RSA + SHA-256). Токен передаётся в теле ответа и дублируется в HttpOnly cookie session_token.

Для защищённых запросов: Authorization: Bearer <jwt>

Claims JWT

Claim Назначение
sub ID пользователя
sid ID сессии в БД
exp Срок действия (Unix time)
iat Время выпуска
iss Издатель (JWT_ISSUER, по умолчанию delez-api)
token_use Тип токена: session

Безопасность

  • Только RS256; список алгоритмов при decode зафиксирован.
  • Длина токена ограничена до декодирования (защита от DoS).
  • Сравнение токенов через secrets.compare_digest (constant-time).
  • JWT_LEEWAY_SECONDS (по умолчанию 120) — допуск по часам.
  • Пароли: SHA-256 с солью.

Генерация ключей

openssl genrsa -out jwt_private.pem 2048
openssl rsa -in jwt_private.pem -pubout -out jwt_public.pem

Передать в переменные окружения: JWT_PRIVATE_KEY_PEM, JWT_PUBLIC_KEY_PEM.

Обратная совместимость

Старые opaque-токены (secrets.token_urlsafe) принимаются, пока сессия есть в БД. Новые сессии создаются только как RS256 JWT.

Настройка CORS

CORS настроен через CORSMiddleware. Разрешённые origins задаются через переменную окружения CORS_ORIGINS:

# JSON формат
CORS_ORIGINS=["https://delez.tech","http://localhost:3000"]
# Или через запятую
CORS_ORIGINS=https://delez.tech,http://localhost:3000

Проверка preflight:

curl -X OPTIONS https://api.delez-repo.ru/auth/sign-up/email \
-H "Origin: https://delez.tech" \
-H "Access-Control-Request-Method: POST" \
-H "Access-Control-Request-Headers: Content-Type" -v

Ключевые возможности

  • Регистрация и аутентификация через JWT RS256.
  • Ведение дневника записей с голосовым вводом (OpenAI Whisper).
  • Построение ризомы — интерактивного графа событий в Neo4j.
  • Диалоги с LLM (GigaChat) с учётом контекста записей через LangGraph.
  • Система экспериментов для проверки личных гипотез.
  • Метрики интенсивности, трансформации, связанные ситуации.
  • Мониторинг через Prometheus + Grafana.
  • CI/CD через GitLab, контейнеризация Docker.
  • Покрытие тестами > 80% (модульные, интеграционные, нагрузочные).
