Detailed Description

@file goals.py
@brief Эндпоинты для работы с целями пользователя.

Цели хранятся в Neo4j как узлы типа Goal. Они связаны с записями дневника
(RELATES_TO) и концепциями (BASED_ON), что позволяет отслеживать прогресс
через граф ризомы.
