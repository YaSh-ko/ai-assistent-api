Detailed Description

@file jwt_auth.py
@brief JWT-токены сессий на алгоритме RS256 (RSA + SHA-256).

Модуль отвечает за выпуск и проверку подписанных токенов. Намеренно
ограничен только RS256, чтобы исключить «algorithm confusion» атаки.
Входная строка токена проверяется на максимальную длину до декодирования —
защита от DoS через огромные payload'ы.

Безопасность:
- Явный список алгоритмов (только RS256).
- Ограничение длины входной строки до декодирования.
- Сравнение токенов через secrets.compare_digest (constant-time).
