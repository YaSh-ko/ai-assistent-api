Detailed Description

@file conversations.py
@brief Эндпоинты для работы с диалогами (Conversation).

Диалог — контейнер для переписки пользователя с LLM. Может быть привязан
к конкретной записи дневника через EntryThread, тогда LLM получает контекст
этой записи. Свободный диалог не привязан ни к чему.
