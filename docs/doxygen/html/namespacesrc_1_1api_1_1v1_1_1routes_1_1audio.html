Detailed Description

@file audio.py
@brief Эндпоинты транскрипции аудио.

Поддерживает два режима:
- POST /v1/audio/transcribe — загрузка файла (WAV, MP3, M4A, WEBM, OGG),
  транскрипция через Whisper, создание Entry. Максимальный размер файла 100 МБ.
- WS   /v1/audio/stream — WebSocket-стриминг: клиент шлёт бинарные чанки,
  сервер возвращает JSON с промежуточными и финальным результатами.

Аутентификация WebSocket: токен в query-параметре ?token=... или
в первом JSON-сообщении {"type":"auth","token":"..."}.
