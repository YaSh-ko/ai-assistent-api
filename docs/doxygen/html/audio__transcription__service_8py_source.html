3@brief Сервис транскрипции аудио через Whisper и создания записей дневника.

5Поддерживает два режима работы:
6- Пакетный (transcribe_file): загружается файл целиком, возвращается готовая Entry.

183 """Sync Entry to Neo4j graph database."""
184 try:

207 "word_count": word_count,
208 "language": language,
209 "duration": duration
210 }
211 )
