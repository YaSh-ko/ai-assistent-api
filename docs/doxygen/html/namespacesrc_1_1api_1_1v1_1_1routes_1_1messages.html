Detailed Description

@file messages.py
@brief Эндпоинты для работы с сообщениями в диалогах.

Сообщения хранятся в PostgreSQL и привязаны к конкретному диалогу.
Поддерживаются реакции на сообщения (лайк/дизлайк и произвольные эмодзи)
для сбора обратной связи по качеству ответов LLM.
