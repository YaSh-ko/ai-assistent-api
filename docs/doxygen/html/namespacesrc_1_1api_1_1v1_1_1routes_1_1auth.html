Detailed Description

@file auth.py
@brief Эндпоинты аутентификации.

Реализует полный цикл работы с аккаунтом:
- POST /auth/sign-up/email — регистрация
- POST /auth/sign-in/email — вход
- POST /auth/sign-out — выход
- GET  /auth/get-session — текущая сессия
- POST /auth/forget-password — запрос сброса пароля
- POST /auth/reset-password — установка нового пароля
- POST /auth/resend-verification — повторная отправка письма
- POST /auth/verify-email — подтверждение почты

Сессионный токен передаётся через cookie session_token или
заголовок Authorization: Bearer <token>.
