Detailed Description

@file neo4j_client.py
@brief Клиент для работы с графовой базой данных Neo4j.

Neo4j хранит ризому пользователя: узлы Entry, Concept, Goal, Experiment,
Analysis и Topic связаны рёбрами, отражающими смысловые отношения между ними.
Клиент предоставляет методы для получения полного графа, поиска по узлам
и навигации по связям.

Все запросы к Neo4j выполняются через run_in_executor, чтобы не блокировать
event loop FastAPI.
