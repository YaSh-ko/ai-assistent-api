Detailed Description

@file entries.py
@brief Эндпоинты для работы с записями дневника.

Запись (Entry) — базовая единица ризомы. Через эти эндпоинты пользователь
создаёт и читает записи, а также получает полный анализ конкретной записи:
метрики интенсивности, связанные ситуации, негативные воздействия,
трансформации и концепции из Neo4j.
